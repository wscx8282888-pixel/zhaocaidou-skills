# 销售口语 → 结构化字段 (LLM 抽取规范)

销售跟你 (Claude) 说的是口语, hub 表要的是枚举值。这份文档定义抽取规则 + 8 个真实场景示例。

## 总原则

1. **能抽就抽, 抽不准宁可留空**。空字段 hub 不动飞书侧值; 错字段会污染表 (虽然不在白名单的值会被 skip)。
2. **跨字段一致性**: `followupStatus="已拒绝"` 应该配 `feedbackQuality="不合适"`; `followupStatus="已成单"` 应该有 `dealAmount`。
3. **日期算到具体日**: "下周一" "明天" "周五" 这种 LLM 自己算出 ISO `YYYY-MM-DD` 再传。今天日期从系统 (例如 `date -I` 或 Claude 自己知道的当前日期)。算不准就留空, 让销售自己说。
4. **金额必须数字**: "5万" → `50000`, "首单 12 万 5" → `125000`, "120k" → `120000`。带"差不多"、"大概"、"几万" → 留空, 让销售确定。
5. **草稿必须给销售看**。LLM 抽完按下面格式列出来, 销售确认后才 POST。

## 字段白名单速查 (跟 setup_lark_base.py 真实选项对齐, 不在白名单 hub 会 skip)

| 字段 | 白名单 |
|---|---|
| `followupStatus` | `未联系` / `已联系` / `已跟进` / `已报价` / `已成单` / `已退回` / `已拒绝` |
| `feedbackQuality` | `质量好` / `一般` / `不合适` |
| `communicationResult` | `线上推进中` / `计划线下拜访` / `放弃跟进` / `跟进后拒绝` |
| `followupNudgeResult` (v0.2 二次催按钮) | `还在推进中` / `拿到决策时间` / `没下文了` |

free text: `unsuitableReason` / `additionalRequest` / **`rawFeedback`** (销售原始口语)
number: `dealAmount`
ISO date: `nextFollowupDate`

## v0.2 关键约定: 永远带 rawFeedback

销售用自然语言反馈时, 不光抽出结构化字段, **也要把销售说的整段原话填到 `rawFeedback`** 一起 POST 进去。这字段会写到飞书表"销售反馈原文"列, 让管理员事后能看到 LLM 抽前的原文 — 如果你 (Claude) 抽错了字段, 管理员能从原文 catch。

例外: 销售只说 "标已联系" / "XX 已成单 5 万" 这种按钮式短指令, 没多余信息, 可以不带 rawFeedback。但任何含上下文/情境/对话内容的消息, 都带上。

## 状态语义 (dowsure 业务模型: 联系 → 跟进 → 报价 → 成单 / 退回 / 拒绝)

- **已联系**: 拨通电话 / 发了微信好友请求 / 发了消息, 但客户**还没正经回应**
- **已跟进**: 有过实质沟通 (含加上微信继续聊 / 客户表态 / 约线下), 客户态度模糊或积极但还没到给方案
- **已报价**: 给了客户具体方案 / 费率 / 额度等可决策的信息, 等他决定
- **已成单**: 签合同 / 付款 / 客户接入业务系统 — 转化成功
- **已退回**: **销售主动**说"这条我跟不动了" — 还给运营, 由管理员决定重派/归档
- **已拒绝**: **客户明确拒绝**或行业不匹配, 销售不再跟

> **"已跟进"和"已报价"的边界**: 给到具体可决策信息 (额度数字、费率表、合同草稿) 后 = 已报价; 在那之前哪怕加了微信聊了很多 = 已跟进。

> **"已退回"和"已拒绝"的边界**: 退回 = 销售主动放弃; 拒绝 = 客户主动拒绝。

## 8 个示例 (覆盖业务模型每个状态)

### 例 1: 加微信 (进入实质跟进)

**销售说**: "杭州那家越禾我加上微信了, 张总说有兴趣了解一下"

**抽**:
```json
{
  "followupStatus": "已跟进",
  "communicationResult": "线上推进中"
}
```

**草稿确认**:
> 我准备这样写:
> - 公司: 杭州越禾 (recXXX)
> - 跟进状态: 已跟进
> - 沟通结果: 线上推进中
>
> 对吗?

### 例 2: 打了没人接 (拨通但没说上话)

**销售说**: "上海艾博那家打了, 没人接, 留了语音"

**抽**:
```json
{
  "followupStatus": "已联系"
}
```

(`feedbackQuality` 留空 — 没接通没法判断质量; `communicationResult` 也留空 — 不算推进)

### 例 3: 客户明确不合适 (客户拒绝)

**销售说**: "深圳那家不合适, 他做的不是亚马逊是 Temu, 不是我们目标用户"

**抽**:
```json
{
  "followupStatus": "已拒绝",
  "feedbackQuality": "不合适",
  "unsuitableReason": "不是亚马逊卖家, 做 Temu"
}
```

### 例 4: 约了线下见面

**销售说**: "广州天裕那家聊得不错, 下周二我去他公司聊"

**今天是 2026-05-25 (周一), 下周二 = 2026-06-02。**

**抽**:
```json
{
  "followupStatus": "已跟进",
  "feedbackQuality": "质量好",
  "communicationResult": "计划线下拜访",
  "nextFollowupDate": "2026-06-02"
}
```

### 例 5: 给了费率/方案 (进入报价阶段)

**销售说**: "兴时达那家我把咱们旺季备货的费率表发给他了, 等他周五拍板"

**今天 2026-05-25 周一, 周五 = 2026-05-29。**

**抽**:
```json
{
  "followupStatus": "已报价",
  "communicationResult": "线上推进中",
  "nextFollowupDate": "2026-05-29",
  "additionalRequest": "已发旺季备货费率表, 等客户周五拍板"
}
```

### 例 6: 成单

**销售说**: "鸿景那家签了, 首单 12 万 8"

**抽**:
```json
{
  "followupStatus": "已成单",
  "dealAmount": 128000
}
```

**草稿强调金额单位**:
> - 公司: 鸿景 (recXXX)
> - 跟进状态: 已成单
> - **成单金额: ¥128,000 (12.8 万)**
>
> 金额对吗?

### 例 7: 跟进几轮后客户拒绝

**销售说**: "翠岚之前还在聊, 今天他说算了他们不考虑外部融资, 自己周转就好"

**抽**:
```json
{
  "followupStatus": "已拒绝",
  "feedbackQuality": "一般",
  "communicationResult": "跟进后拒绝",
  "unsuitableReason": "客户自有现金流充足, 不考虑外部融资"
}
```

(注意 `communicationResult="跟进后拒绝"` 跟 `已拒绝` 配对, 区分例 3 那种一开始就不合适的)

### 例 8: 销售自己退回 (跟不动了)

**销售说**: "天宇这条我跟不下去, 联系不上, 你们公海里挂着或者重派吧"

**抽**:
```json
{
  "followupStatus": "已退回",
  "communicationResult": "放弃跟进",
  "additionalRequest": "联系不上客户, 销售主动退回"
}
```

(写完后, 管理员会看到 `跟进状态=已退回`, 决定退公海池还是重派给别人。注意销售自己**不能改 `分配状态`** — 那是 `/assign` 端点, 管理员独占)

## 边界情况

### 客户要更多资料但还没到报价

"客户让我发份公司介绍" → 还是 `已跟进` + `additionalRequest`, 不是 `已报价`。报价指给到具体可决策的数字 / 方案。

### 销售提到多家公司

"我今天联系了 5 家, 都标已联系吧"

→ 列出"你说的 5 家是: A, B, C, D, E, 对吗?" 让销售确认每家都在他名下。**批量操作要更谨慎**, 逐条 POST 不要并行 (一条失败容易遗漏)。

### 销售给了 recordId 不在他名下

"recABCD 这条标已联系"

→ 先 GET /ai-leads 过滤 assignedTo == 我, 检查 recABCD 在不在结果里。不在 → 拒绝: "recABCD 不是分配给你的, 我不能改"。

### 销售口语跟字段冲突

"已经成单了, 但还在跟进中"

→ 不要硬抽。问销售: "成单了应该是终态了, 还在跟进是什么意思? 是已成单但还有交付要跟? 还是其实没完全成?"

### 模糊语气

"翠岚那家差不多算成了吧"

→ **不要直接抽**, 反问:
> "差不多算成是什么意思呢? 是已经签合同了 (已成单), 还是给了报价等他拍板 (已报价), 还是只是口头同意 (已跟进)? 有金额吗?"

抽到能 commit 的具体描述再写草稿。

### 日期不确定

"下周吧, 具体哪天看他时间"

→ `nextFollowupDate` 留空。回话: "下周具体哪天确定后再告诉我, 我帮你写上"。
